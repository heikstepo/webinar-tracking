1. Get my NDA-protected & private ranges, entries, workbooks, and more…
2. Execute it consistently, with me working on your trades directly…

Header box is sized to the two lines the header actually needs. Items share one
size (45pt) so the section holds still as it advances, and the numeral travels
with its text as one centred group, so every slide balances regardless of how
long the point is.

Accent lands on NDA, consistently, and prop firm.

Verified: all four strings present character-exact, 0 overflows, 0 margin
violations. Needs Poppins Bold installed.
