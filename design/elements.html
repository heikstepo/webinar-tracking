The element kit behind the Find the weakest link deck — Apple's structural restraint carrying a marker-and-whiteboard teaching voice. Tokens, type scale, and every reusable part, rendered live at slide scale.

01

The read

What the existing deck is actually doing — the rules I extracted before building anything, so new slides land in the same world rather than merely nearby.

Structure

Apple's discipline, not Apple's voice

One idea per slide, enormous negative space, a single accent, content held off a hard left margin. But where Apple caps headlines at weight 600 and neutral tracking, these run 900 with −0.022em. The skeleton is Cupertino; the volume is a whiteboard.

Ground

Never pure white

Everything sits on a cool near-white wash (#F5F6F7 → #FCFCFD). That single choice is what lets a white card, a white table row, and a hairline panel all read as separate objects without a drop shadow doing the work.

Color

Four accents, one job each

Blue is structural, yellow is the idea worth keeping, red is the problem, green is the good outcome. Blue and green are Facebook's own — the palette quietly belongs to the platform being taught.

Emphasis

The highlighter is the whole system

A solid rounded block behind one phrase per headline. Yellow keeps black text because it behaves like a real highlighter; blue, red and green invert to white because they behave like labels. Two marks in one headline and the hierarchy collapses.

Warmth

A human hand on a machine grid

Caveat handwriting, outlined hand-drawn numerals, a sagging underline, a red arrow pointing at the outlier. The geometry stays rigid; the annotation layer is what makes it feel taught rather than published.

Restraint

Slides are allowed to be half empty

Several slides carry a headline and four chips, then stop. The lower third is left genuinely blank. Filling it is the fastest way to break the style.

Using it

Same workflow that produced the original deck: author in HTML, print to PDF from Chrome.

  1. Copy slide-template.html, add one <section class="slide"> per slide.
  2. Open it in Chrome → Print → Destination Save as PDF, Margins None, Scale 100%, Background graphics ON. Each slide exports as one 1440×810 page.
  3. Run python3 build-standalone.py deck.html to fold the CSS and font into a single portable file for sharing or embedding.
